# Mini Productivity App — Expense Tracker

A responsive expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add, categorize, and remove expenses
- Filter by category (`All`, `Food`, `Transport`, `Shopping`, `Utilities`, `Other`)
- See total spend, expense count, and category count
- Preserve expense data in browser local storage
- Responsive design for desktop and mobile

## How to use

1. Open `index.html` in a browser.
2. Enter an expense title, amount, and category.
3. Click `Add expense` to save it.
4. Use the category filters to view specific expenses.
5. Press `Clear all` to reset the tracker.

## Challenges

- Designing a clean expense form that works well on smaller screens.
- Ensuring amounts store and format correctly while preserving local storage state.
- Keeping the summary counters synchronized with current expense data.

## Demo

Open `index.html` locally to use the expense tracker.
